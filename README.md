# Yueji

Yueji 是一款 Android 本地记账与基金资产管理工具。它以**账户真实余额的变化**整理日常支出，同时提供收入、报销、负债台账、普通基金持仓、银行理财和自选基金管理。

- 当前版本：**4.7.3**（内部构建号 22）
- 支持系统：Android 8.0 及以上
- Android 包名：`cn.yueji.balance`
- [GitHub 项目](https://github.com/risnerohman625/Yueji) · [Gitee 项目](https://gitee.com/risnerohman576/yueji)
- [GitHub 下载与发布记录](https://github.com/risnerohman625/Yueji/releases) · [Gitee 下载与发布记录](https://gitee.com/risnerohman576/yueji/releases)

## 主要功能

### 账户与资产

- 管理银行卡、支付宝、微信、现金等账户，记录指定时间的真实余额。
- 查看账户余额历史、资产构成、资产趋势和月度/年度统计。
- 用各账户自身的连续余额记录计算变化，不把未更新账户补成零余额。

### 收入、支出、报销与负债

- 收入支持标签分类、查询和统计；新增收入关联账户后自动记录到账。
- 大额支出用于标记已经反映在余额变化中的消费，避免重复计算。
- 报销支持垫付、分次到账、待报销和部分报销状态，垫付与到账可分别关联账户。
- 负债及还款作为独立台账展示，不自动增加收入、扣减账户或改变总资产。
- 支持导入历史月支出，并按截止时间与后续余额记录衔接。

### 普通基金持仓

- 按六位基金代码、名称、买入金额、手续费和时间管理买入批次与卖出记录。
- 通过公开净值资料计算份额、持有价值、持有收益及累计收益，并展示收益趋势和日历。
- 支持买入详情截图 OCR 和 XLSX 导入；截图中的完整基金名称须与查询结果逐字匹配，存疑项需人工核对。
- 买入、卖出可选择关联资金账户，也可明确不关联，避免补录历史交易时重复扣款。
- 支持每周/每月定投计划与实际执行记录；**不会自动下单或从银行扣款**。
- 从首页删除基金后冻结并保留当时收益；可在累计收益中恢复，永久删除则清除相应记录。

### 银行理财

- 根据手动录入或上传的实际余额、收益及交易证据管理产品。
- 支持申购、赎回和产品变化记录，可关联实际资金账户。
- 不用普通基金净值猜测银行理财收益，也不为缺失日期虚构日收益。

### 自选基金

- 作为行情观察名单，与实际已购持仓分开管理，不凭关注记录增加资产。
- 支持手动代码添加、自选列表截图 OCR、全部/持有/自定义分组与批量分组、删除。
- 支持周期切换和涨跌幅、夏普比率、最大回撤排序，指标区域可左右滚动。
- 详情提供业绩走势、最大回撤与修复标记、成立时间、基金规模及公开费率资料。
- 下拉刷新行情；删除自选不会删除已购基金及其交易。

### 备份、安全与个性化

- XLSX 模板导入导出收支报销、历史数据和基金买入记录。
- 完整 JSON 备份与恢复；当前格式为 11，可读取格式 1–11。
- 应用锁、生物识别、系统通知和安装来源权限入口。
- 浅色/深色/跟随系统、主题色及三种内置图标。
- 提供 GitHub/Gitee 更新源选择，读取公开 Release 并下载安装包，经包名、版本号及签名检查后交给 Android 安装器。
- 设置内提供分类使用说明，首次使用或升级后需在前台阅读至少 10 秒。

## 使用前须知

### 本软件不是单纯逐笔累加消费的账本

日常支出主要来自账户的真实余额差，再结合收入、报销和投资划转调整：

> 期初余额 − 期末余额 ＋ 收入 − 非消费流出 ＋ 非消费流入

请按实际时间更新真实余额。关联账户的收入、垫付、报销到账和投资交易会记录资金变化，不要再人为重复加减同一笔交易。缺少余额区间不等于该期间真实零支出。

### 三类基金管理不能混用

| 类型 | 用途 | 数据依据 |
| --- | --- | --- |
| 普通基金 | 实际买入批次、持仓和收益 | 买卖记录、公开净值及相关事件 |
| 银行理财 | 实际理财产品与资金变化 | 手动/上传的余额、收益和交易证据 |
| 自选基金 | 观察行情与比较指标 | 公开行情，不代表实际持仓 |

截图 OCR 可能识别错字、代码或数字，请核对产品份额、金额、手续费和时间。不同 A/C 份额不是同一代码。历史交易不要在没有确认的情况下关联账户。

夏普比率采用日收益、252 交易日年化及无风险收益率 0 的计算口径，并非官方评级。历史不足、未获取费用和缺失行情应结合页面状态理解，不能当作真实零收益或零费用。交易确认、锁定期、限购和实际费率以基金公司及销售平台最新公告为准。

## 安装与升级

在仓库的 **Releases / 发行版** 页面下载 APK；也可从仓库 `dist` 目录取得安装包与 SHA-256 校验文件。

1. 升级前先在设置中导出完整 JSON 备份。
2. 使用与已安装软件签名相同的新 APK 覆盖安装，**不要先卸载或清除数据**。
3. 安装来源权限和安装确认由 Android 系统控制，软件不能静默安装或强制重启。

目前分发的 `Yueji-4.7.3-debug.apk` 是使用既有开发证书的 Debug 构建，以保持现有用户的覆盖升级兼容性。文件名中的 `debug` 不是 Android 包名；重命名不能改变构建类型或签名。改用正式签名需要另行安排升级与数据迁移。

## 数据来源与隐私

- 账本保存在本机，交付软件不内置个人账户、基金或测试记录。
- 截图 OCR 使用设备本地模型执行，不需要上传图片。成功导入后可按选项清理来源图片，系统要求的删除授权仍需用户确认。
- 普通基金公开净值与产品资料来自东方财富/天天基金，交易日历使用 holiday-cn 开源数据；行情不是实时成交报价。
- GitHub/Gitee 用于项目与安装包分发，检查更新不上传本地账本。
- 公开仓库排除账本、授权凭据、签名私钥、缓存、私人工作簿和测试图片。
- 更多信息见 [隐私说明](docs/PRIVACY.md)。

## 构建与测试

项目使用 Java 17、Android SDK 36、最低 API 26。Android Studio/SDK 的本机路径通过本地配置管理，不应上传 `local.properties`。

普通 Gradle 构建：

```bash
./gradlew assembleDebug lintDebug
./gradlew assembleDebugAndroidTest
```

Windows 本机脚本目前使用 `D:\ProgramData\Android` 下的 Android Studio 和 SDK：

```powershell
.\tools\build.ps1 -Check
.\tools\test-data.ps1
.\tools\build-androidtest.ps1 -Check
.\tools\test-device.ps1 -Serial emulator-5554 -Classes cn.yueji.balance.V473UiTest
```

设备测试只应运行在专用模拟器，不能对用户手机账本执行测试注入。真实 OCR 截图测试需要自行提供私有测试素材；公开仓库不包含用户订单截图。4.7.3 本地验证通过 312 项数据测试和 26 项设备测试，构建与 lint 通过；测试记录见 `docs/validation`。
