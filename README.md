# Yueji 4.7.0

Android 本地记账与基金资产跟踪工具。此目录是从 Yueji 4.6.6 完整复制后独立修改的 4.7.0 版本；4.6.6 原目录保持不变。

## 本版更新

- 资产页：资产构成选择器改为带卡片背景的左右三角控件，统一标题字号；环形图引线按名称与比例分两行显示，点击扇区显示金额与真实比例。
- 基金账户联动：新买入可选择资金来源账户，卖出可选择资金到账账户；历史交易可明确选择“不关联账户”。关联交易会在对应账户历史中生成现金变动，月支出计算不会重复计账。
- 定投：普通基金支持每周/每月计划、执行日、金额、手续费和必选资金账户；软件只登记用户实际完成的买入，不会自动扣款。详情页可查看、暂停和查看历史定投记录。
- 自选基金：支持全部、持有和自定义分组；支持支付宝自选截图 OCR 识别基金名称/代码、周期切换、涨跌幅/夏普比率/最大回撤排序、横向指标表和长按迁移确认。
- 自选详情：显示区间涨跌幅、成立日期、距今时间、规模、业绩走势/回撤修复图、可拖动日期游标及买入/卖出规则卡片。费率、锁定期和规模使用公开披露；未取得的数据明确显示待核对。
- 数据兼容：JSON 备份升级到格式 11，读取 1-11；旧备份缺少新字段时默认不关联账户、无定投和空自选数据。
- 设置页：加入公开仓库入口：[github.com/risnerohman625/Yueji](https://github.com/risnerohman625/Yueji)。

## 构建与测试

Android Studio/SDK 目录：`D:\ProgramData\Android`。

```powershell
$env:JAVA_HOME='D:\ProgramData\Android\AndroidStudio\jbr'
.\tools\build.ps1 -Check
.\tools\test-data.ps1
.\tools\build-androidtest.ps1 -Check
.\tools\test-device.ps1 -Serial emulator-5554 -Classes cn.yueji.balance.V470UiTest
```

测试仅使用 Android 模拟器临时账本，交付应用不内置测试账户、基金或个人记录。基金行情来自东方财富公开接口；费率/成立日期/规模来自天天基金公开档案，实际交易以基金公司和平台公告为准。

## 数据与隐私

账本默认保存在本机。截图 OCR 在设备本地执行；截图导入完成后可按勾选清理已提交的来源图片。公开仓库不包含本机账本、授权凭据、构建缓存或用户测试图片。

## 安装与验证

安装包：dist/Yueji-4.7.0-debug.apk（Android 8.0+）。升级前先导出完整JSON备份，再覆盖安装，不要卸载或清数据。包名cn.yueji.balance与原调试签名均保留。

最终数据测试308项、新版设备测试17项、旧版核心设备回归41项通过；构建与lint通过，lint仍有项目既有及代码风格警告。完整验证见docs/validation。各行指标采用等宽居中；成立时长为x年x日，不足一年只显示天数。

公开仓库以4.7.0作为首个快照，不上传4.6.6及更早版本。旧版测试类是当前回归测试，不是旧版本源码快照。私有历史/图片测试素材不公开；可选历史工作簿测试在缺素材时跳过，常规合成数据测试可独立执行。
