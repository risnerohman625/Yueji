# Yueji 4.7.5 / build 24

- 最大回撤修复天数从回撤谷底开始计到首次恢复原峰值，按自然日。数据显示本时期极值时允许回撤过程中反弹。增加 007329 截图对应的公开历史序列回归样本。
- “本时期最高下跌幅度”是选定区间最大回撤：相对先前峰值到之后任意低点取最大值，不限定单调下跌。说明复合涨幅与百分点差的区别。
- 收市后自动更新在交易日北京时间15:00后运行，间隔仍由原设置控制，默认2小时。基金页面/自选页面首次访问额外检查。已购与自选按代码合并单次请求，并将同一行情结果写入两处。
- 仅净值日期达到当天且历史抓取完整时才标记该代码更新完成。没公布、旧净值、接口失败在下个间隔重试；所有代码完成后静默停止当日轮询。系统调度仍可能延迟。手动下拉更新不受限。
- 自选手动代码导入成功/失败横幅显示在屏幕上方约三分之一。基金持仓卡片缩紧名称、指标、尾部与卡片间距。
- 更新检查采用固定底栏上方的版本面板，展示短说明、稍后/立即更新和下载进度；网络/校验失败显示在进度区域，提示切换更新源。最新版横幅显示在距底部约四分之一处。
- 稳定安装入口改为主界面 Activity 本身，图标别名指向此入口；保留 MainActivity 原 SharedPreferences 名，避免升级后图标/主题等设置丢失。

验证：326 项 JVM 数据测试，50 项模拟器设备测试，构建和 lint 通过；模拟器启动入口测试验证同一主界面实例与任务。安装器“打开”行为仍受厂商系统影响，须真机覆盖升级复核。
