# Yueji 4.7.2

- 版本名 4.7.2，versionCode 21；在 YuejiV4.7.1 独立复制目录上修改，旧项目不覆盖。
- 已购基金截图导入恢复为识别买入产品名称并逐字匹配公开基金数据库；手动买入同时填写基金名称和六位代码，联网获取净值时再次校验名称与代码。自选基金截图仍只识别六位代码，名称由代码查询。
- 自选列表移除页面刷新按钮，整页下拉刷新；添加按钮与周期控件等宽；长按进入批量选择模式，底部提供取消、添加到、删除；分组操作支持选择目标分组及是否从当前组移除。
- 自选列表压缩条目高度，排序箭头紧凑竖排，移除列表底部操作说明文字。
- 自选详情页折叠时将标题、基金名、指标、图表、周期和买卖规则卡片压缩到首屏；基金名用边框区分；规则卡片始终显示。
- 买入/卖出规则切换只更新规则内容，不重绘整个详情页；费率数字加粗，原费率与优惠费率并排对齐，优惠费率橙色显示，优惠说明简写为“优惠”。
- 规则来源数据继续保持缺失不猜测为零；公开费率页与概况页分开获取。
- 设置一级卡片完整使用主题色背景，二级数据管理卡片使用淡紫色且缩小间距；已是最新版本横幅放在页面底部区域；设置页不展开时压缩卡片间距。
- 软件说明保留在设置页，删除自选列表底部夏普说明等重复操作提示。
- Git 远程同时配置 GitHub 与 Gitee：GitHub `risnerohman625/Yueji`，Gitee `risnerohman576/yueji`；全局提交作者可以与远程登录账号不同，远程认证由凭据管理器独立处理。
