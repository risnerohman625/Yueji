# Yueji 4.7.10 / build 29

从 YuejiV4.7.9 完整复制，原版本不改动。包名 cn.yueji.balance、既有开发证书不变；交付APK无测试账本，不含OCR。

## 账户与余额

- 新增、编辑账户均可设置启用时间和对应初始余额，可早于在软件中添加账户的时刻；启用后历史基金交易可关联。
- 所有余额卡片，包括初始、手动及自动余额，左滑显示“编辑”“删除”；可编辑对应时间和金额。
- 编辑 / 删除只处理当前账户这一条余额，不连带更改同一时刻其他账户。不允许编辑到此账户已有记录的目标时刻，以免静默覆盖。
- 初始启用时间不得晚于已保留余额或关联交易，避免把已存在交易移出账户有效区间；先调整相关记录再移动。
- 初始余额删除后不把缺失记为真实零余额。首条保留余额成为计算起点，之前的资产历史保持未知；完全无余额时账户显示待录入，总额仅合计已知余额。
- 删除自动余额保留原收入、报销和投资流水及其资金影响，不在重算或重启时复活该余额卡片；后续自动余额仍从已知起点按保留流水计算。
- 移除固定每月两次更新、待补节点、固定日期设置和余额更新提醒；升级取消旧待执行闹钟、旧通知和渠道。基金行情刷新 / 收益通知不变。

## 使用说明与提示

- 首次 / 升级使用说明改为滑到内容最底部后启用“我已阅读，开始使用”，无强制10秒等待，返回不能绕过确认；已阅读状态仍按版本保存。
- 大宗支出、报销、负债、自选、基金购买及账户起点 / 余额记录等易误解位置提供圆圈感叹号。
- 点击在符号旁显示深色半透明短说明，位置按可用屏幕边界调整，点击外部 / 返回关闭；普通字段不批量添加说明。

## 备份与升级

JSON格式15兼容读取1–15，新增 openingKnown 与 skippedCashObservations。旧账户默认保留原初始余额，旧固定更新设置忽略；格式15旧版不可读。SQLite版本4和XLSX模板 / 月历史衔接口径不变。更新前导出完整JSON，使用同签名APK覆盖安装，不卸载、不清数据。
