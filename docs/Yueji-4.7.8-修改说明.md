# Yueji 4.7.8 / build 27

- 完整复制4.7.7后修改，原目录保持不动；包名和签名保持一致。
- 新增“每日”定投，下一期跳过周末和已加载日历中的休市日；未覆盖年份须核对日历。仍为实际买入登记计划，不自动下单、不自动扣款。
- 可配置计划总期数，0表示不限，1–10000表示有限期数。按已登记实际买入计数，满期停止；允许修改总期数后继续。历史记录保留。
- 添加普通基金买入时，输入完整代码后查询名称和申购费率；优先使用已缓存资料，无缓存才联网读取。按适用金额档位的末列优惠百分比×买入金额估算，四舍五入至分，支持0费率。
- 金额变化会重新估算；用户手动修改或清空手续费后，该表单不再覆盖。编辑历史交易和登记定投使用原值/计划值，不擅自改动。
- 固定按笔收费或未知费率不猜测；提示手动填写。平台优惠与实际扣费可能不同，估算公式依用户要求，不替代成交确认单。
- 新增独立两瓣通知小图标资源，使用现有两瓣标志路径，放大清晰显示；更新时重设既有应用通知。Android通知小图标由系统显示为单色，不能强制彩色照片；系统/OEM缓存效果需真机验证。
- JSON备份格式13保存总期数，兼容读取1–13；旧备份默认不限。旧版本拒绝新格式，升级前备份，勿直接降级。
