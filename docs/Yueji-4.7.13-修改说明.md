4. 已购基金详情右上角增加更多。已主动加入watchFunds的基金直接进入自选详情；只有虚拟持有身份、未主动加入的显示灰色但可点击，先询问加入并查看。确认时复用已有身份 / 行情，不新增买入、不改持仓，取消不改数据。
5. 已核实公开费用页可返回明确的日累计申购限额，也有明确无限额。代码行后方蓝字显示限制单日买入xx元，不用最低购买金额、单笔限额或暂停申购状态猜测。该限额为数据源披露值，不代表开放申购，仍以实际交易平台和公告为准。
6. 新建转账默认填入所选转出账户当前全部已知账面余额，可改；换转出账户重新填入。未知余额留空，编辑已有转账保留原金额。新建时间保留当前秒，避免早于同分钟刚建立的真实余额或账户启用时刻；保存仍需用户确认，不发起真实付款。

## 自动定投组的边界

- 定投是自动限购分类组，不是购买计划，不会自动下单或给基金建立定投。
- 确认存在日限额后第一次归类：移除原自定义组和显式全部关系，进入定投；自动持有视图也不再重复展示，但实际已购持仓 / 金额不变。
- 用户随后可添加到其他自定义组 / 全部，并保留定投。重复刷新不会清掉这些后来添加的关系。
- 不能在添加分组中选择定投，不能手动把其他基金送入、改名或删除该系统组。明确披露不限额后自动移出，网络失败 / 未知不清空既有已确认值。
- 旧版同名自定义组改名为定投(原分组)等，原关系保留，不把用户自建组误当成系统判断。
- 限购资料独立于NAV是否当天完整；访问自选列表 / 详情按代码检查当天资料，手动刷新可重试。后台写入检查恢复epoch和页面生命周期，旧表单保存保留更新的限额。单次请求有截止，失败不改交易或伪造限额。
