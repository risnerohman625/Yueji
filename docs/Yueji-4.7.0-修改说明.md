# Yueji 4.7.0 修改说明

日期：2026-10-25。versionCode 18，versionName 4.7.0，包名继续为 `cn.yueji.balance`。

本版从 `YuejiV4.6.6` 完整复制到 `YuejiV4.7.0` 后修改，旧目录未覆盖。

## 账户关联

基金买入批次可选择资金来源账户，卖出批次可选择到账账户；默认选择当前首个有效资产账户，但历史记录可以选择“不关联账户”。关联交易按北京时间转换为本机账本时间，作为单账户现金流参与账户余额和月支出校正；同一时刻的手工实际余额优先，不重复扣款。银行理财初始买入及已完成买卖事件也支持账户关联，待完成事件不改变现金余额。

## 定投

定投计划包含周期（每周/每月）、执行日、金额、手续费、开始日期和必选资金账户。计划不会自动访问银行或基金平台，也不会自动扣款；用户完成实际买入后，通过“登记本期实际买入”建立买入批次和定投记录。编辑、删除或跨代码修正时，记录按不可变买入批次 ID 迁移或标记。

## 自选与详情

自选列表支持全部、持有、自定义分组；“全部”不允许移除，“持有”完全由已持有基金同步。截图 OCR 只提取基金代码并逐只联网核验，名称不逐字一致时要求人工确认。自选详情按公布的日收益率累计总回报；周期不足时指标显示 0.0/暂无历史，不用最新值回填过去。回撤修复显示最大回撤、修复天数或“正在修复中”。
