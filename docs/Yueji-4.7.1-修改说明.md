# Yueji 4.7.1

- 版本号 4.7.1，versionCode 19，独立复制 4.7.0 后修改，原目录未编辑。
- 自选工具栏改为自定义分组入口，紧凑周期列表；排序三角在标签右侧竖排。
- 详情改为独立标题、下拉刷新、日期注释、数值底边对齐、纯数值规模、固定图高、图下横滑周期。
- 规则展开后滚到底部，买卖页切换保留滚动位置；费率文字和数字分列对齐。
- 回撤使用两个绿色起止点、一个红色修复点和两个小标签，移除粉色矩形；纵轴使用规整等距刻度。
- 六位代码是基金份额身份，不再用截图名称交叉验证。不同 A/C 份额有不同代码；OCR 误识别成另一有效代码仍可能发生，因此保留人工代码核对。没有代码的已购详情截图必须补全代码，不能仅靠名称导入。
- 已购截图仍提取金额、手续费、购买时间；修改确认页不能编辑基金名称。
- 长按可添加分组、新建分组或删除自选；删除不动已购基金和账户，持有组继续自动同步已购基金。
- 加入用户提供的标准自选截图，真实图片 OCR 测试覆盖 006431、006636、021409、018192、020716、022213。
- 公开费率页与概况页分别获取，部分失败不会丢弃另一页；概况页补充运作费率。缺失费用明确提示，不当作零。
- 设置一级标题浅主题色、展开分隔线；关于卡片先显示 GitHub 图标/链接，再显示其他文字。

## 数据校正验证

2026-10-26 实时查询东方财富公开数据：021675 最新净值日 2026-10-23，净值 1.0721；近一年 5.31434%（显示 5.31%）、成立来 7.21%。旧算法连续乘已四舍五入日收益造成偏差；新版普通日按精确净值比计算，分红/拆分日保留事件收益因子，周期截止最新已公布净值日，不生成休市日曲线点。
006431 买入费率、卖出费率、管理/托管/销售服务费均实测获取成功。
单日限额仅在公开资料明确返回时显示；未披露时不猜测具体限额，交易时以销售平台公告为准。
