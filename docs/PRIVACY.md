# 数据与公开仓库

本机账本、历史工作簿、原始 OCR 图片、旧版本 APK、Gradle 缓存、SDK 路径和签名私钥不提交到公开仓库。主应用不内置个人记录或测试持仓。仓库中的测试代码使用合成数据；涉及本地图片或历史文件的专项测试需要自行提供素材。

本版无OCR或截图读取功能。查询基金资料只向公开数据服务发送基金代码或名称。用户明确配置后的定投只自动生成本地记账记录及关联账户账面变化，不会连接银行或平台下单、扣款。费率优惠、锁定开放日和规模以基金公司及交易平台最新披露为准。安装包使用 Android Debug 签名，不是商店发布签名。

账户之间的转账只记录本地账面资金变动，不发起真实支付，不向支付宝、微信或银行发送转账请求。
